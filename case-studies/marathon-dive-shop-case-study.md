# Case Study: Marathon Dive Shop — Mobile Redesign + Online Booking

## The Client

Marathon Dive Shop is a full-service scuba and snorkeling shop in Marathon, FL. They offer gear rentals, PADI certification courses, guided reef dives, and equipment sales. Strong word-of-mouth but a 2016 website broken on mobile.

## The Problem

- 72% mobile bounce rate — unusable on phones
- 8+ second load time on mobile
- Gear rental required phone call or walk-in
- No PADI course signup flow
- Dive site content was buried and outdated
- Competitors had modern mobile sites capturing the same traffic

## What We Built

A complete mobile-first rebuild:

- **Mobile-first architecture** — every layout decision for 375px screens first
- **Online gear rental system** — select equipment, choose dates, pay deposit
- **PADI course enrollment** — Open Water through DiveMaster with signup forms
- **Dive site guide** — Sombrero Reef, Coffins Patch, Delta Shoal with depth/visibility/marine life info
- **Performance overhaul** — WebP + lazy loading + Next.js SSG cut load time from 8.2s to 1.4s
- **Trip booking + calendar** — guided reef dives with real-time availability

## The Results

| Before | After |
|--------|-------|
| 72% mobile bounce rate | 37% bounce rate (−35 points) |
| Desktop-only 2016 site | Fully responsive mobile experience |
| Gear rental by phone only | Online reservation with deposit — 24/7 |
| No course booking online | PADI sign-ups via site |
| 8.2s mobile load time | 1.4s mobile load time (83% faster) |

## Key Metrics

- **−35%** bounce rate in first 30 days
- **3×** mobile conversions
- **1.4s** mobile load time (down from 8.2s)
- **3 weeks** build & launch
